\doxysubsection{Detailed Description}
A threadsafe wrapper over \doxylink{class_s_q_l_database}{SQLDatabase} which adds inserts to a bounded length queue instead of inserting them immediately.

Inserts are handled in batches via the \doxylink{class_buffered_s_q_l_database_ad3e0f4af4bb8b151e5acf98776a535be}{Buffered\+SQLDatabase\+::run\+\_\+storage\+\_\+loop} method, which should be ran in it\textquotesingle{}s own thread.
