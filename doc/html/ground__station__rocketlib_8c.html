Process the incoming byte and add it to a buffer. If a complete command has been parsed, the command type will be returned and an acknowledgement packet will be added to the GroundStationLink's send buffer

Parameters
gslA GroundStationLink object
inputted_byteThe recieved byte
Returns
The new buffer size. If the value is negative, then the complete message has been recieved (the length is the absolute value of the returned value)

Note that the return type GSRL_CMD_OOM_ERROR indicates that the byte was not parsed due to the ground station's recieve buffer being full. If GSRL_CMD_EMPTY is returned, then no command was recieved and no action is required.

◆ verify_crc8_hash()

bool verify_crc8_hash ( const uint8_t * data,
const size_t data_size )

Returns true if the crc8 hash is valid for this data. It assumes that the 8-bit crc hash immediately follows the data

Parameters
datapointer to the data that the hash should be verified for (last byte should be the hash)
data_sizesize of the data in bytes (including the hash byte)

Note that size includes the hash byte. In other words, if you want to verify the hash of n bytes, pass in an n+1 byte array where the first n bytes are the data and the n+1-th byte is the hash. data_size should also equal n+1.

Returns
true if the hash was valid, and false otherwise
